# Prompt Log
## Задание средней сложности: 1. Разработка сборщика данных на Go.
### Промпт 1
**Инструмент:** OpenCode \
**Промпт:** Реализуй на Go программу, которая собирает данные из источника, указанного в варианте. Использовать горутины для параллельного сбора (если применимо). Данные должны сохраняться в JSON-файлы (каждый объект на отдельной строке).
**Результат:** Реализован Go-сборщик для варианта 16 (Мониторинг производственного оборудования, Modbus/OPC эмуляция).

### Итого
- Количество промптов: 1
- Что пришлось исправлять вручную: ничего.
- Время: ~10 мин

## Задание средней сложности: 2. Добавление буферизации и пакетной записи.
### Промпт 1
**Инструмент:** OpenCode \
**Промпт:** Необходимо модифицировать сборщик: добавить канал с буфером, реализовать пакетную запись (накопить N записей или ожидать T секунд перед записью в файл). Цель — снизить количество операций ввода-вывода.
**Результат:** вместо 6 записей каждые 10 с (6 I/O операций в минуту), теперь ~12-18 записей каждые 20 с (3 I/O операции в минуту) — снижение в ~2-3 раза.

### Итого
- Количество промптов: 1
- Что пришлось исправлять вручную: ничего.
- Время: ~10 мин
